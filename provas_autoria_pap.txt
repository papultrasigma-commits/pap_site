9. MOSTRAR PROBLEMAS QUE RESOLVI

Explicar problemas reais que apareceram durante o desenvolvimento é uma prova muito forte, porque mostra processo e não apenas resultado final.

Problemas que resolvi:
- Reset password só funcionava em localhost
- Conta Valorant vinculava mas não mostrava nome nem tag
- API devolvia name e tag vazios
- Tive de usar fallback com o Riot ID escrito pelo utilizador
- Rank desaparecia quando a API falhava
- Tive de guardar cache local das estatísticas
- Win rate estava errada porque a API podia devolver as equipas em formatos diferentes
- Problemas de Git com conflitos no package.json
- Problemas ao atualizar o GitHub com o branch main

Isto mostra que o projeto foi desenvolvido, testado e corrigido por mim.


10. PERGUNTAS TÉCNICAS QUE POSSO RESPONDER

Pergunta:
Onde guardas a conta Riot?

Resposta:
Guardo na tabela profiles, nas colunas riot_account e riot_puuid.

Pergunta:
Como evitas que duas pessoas usem a mesma conta Valorant?

Resposta:
Uso o riot_puuid, que identifica a conta Riot de forma única.

Pergunta:
Como vais buscar o rank?

Resposta:
Uso a HenrikDev API com Riot ID, tag, região e plataforma.

Pergunta:
O que acontece se a API falhar?

Resposta:
A app mantém os últimos dados em cache local para não mostrar tudo vazio.

Pergunta:
Como proteges páginas privadas?

Resposta:
Uso Supabase Auth para controlar a sessão do utilizador.

Pergunta:
Como sabes se um utilizador é admin?

Resposta:
Verifico o campo is_admin na tabela profiles.

Pergunta:
Onde ficam as equipas?

Resposta:
As equipas ficam na tabela teams e os membros na tabela team_members.

Pergunta:
Como funciona o feed?

Resposta:
As publicações ficam em feed_posts, os comentários em feed_comments e os likes em feed_likes.
